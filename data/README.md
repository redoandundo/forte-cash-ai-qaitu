# Локальный датасет Datathon26

Исходный датасет не хранится в GitHub.

После получения официального архива участник размещает данные локально:

```text
data/open/
├── open_labels.xlsx
└── videos/
    └── *.mov
```

Вся директория `data/open/` игнорируется Git. Видео и labels разрешено использовать только в рамках Datathon26. Их нельзя публиковать, передавать третьим лицам или отправлять во внешние AI API.
