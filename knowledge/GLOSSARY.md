# Глоссарий

| Термин | Значение |
|---|---|
| possible violation | признаки возможного нарушения, требующие ручной проверки |
| event | объединённый временной интервал с повышенным model score |
| peak time | момент максимального score внутри события |
| evidence | JPEG-кадр, связанный с временной точкой события |
| temporal window | последовательность кадров за ограниченный интервал |
| predictor | адаптер, превращающий окно кадров в score |
| manifest | машиночитаемое описание версии, входов и выходов model artifact |
| preprocessing | правила RGB, resize, crop, normalization и sampling |
| parity | проверка близости выходов исходной и экспортированной модели |
| handoff | воспроизводимая передача результата следующему участнику |
| integration branch | временная ветка для совместной проверки компонентов |
| RTF | отношение времени обработки к длительности видео |
