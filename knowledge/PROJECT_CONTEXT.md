# Контекст проекта ForteBank Video Compliance

## Проблема

Проверка кассовых видеозаписей вручную требует времени. Проект помогает находить подозрительные временные интервалы и предоставляет наблюдаемые evidence для человека.

## Исходные данные

- Минимум 40 постановочных видео `.mov` длительностью примерно 10–145 секунд.
- Ракурс сверху, одна камера, одна касса; звука нет.
- Для каждого видео дана бинарная метка и таймкод, но тип нарушения не указан.
- Тестовые видео похожи на обучающие; финальная проверка включает другой угол съёмки.
- Подробные labels, metadata и dataset-derived review хранятся только локально и не публикуются.

## Проверяемый первый milestone

Бинарное обнаружение признаков возможного нарушения и временная локализация. Система не должна обучаться на выдуманных многоклассовых labels.

## Ограничения интерпретации

По видео нельзя автоматически утверждать:

- юридический факт нарушения;
- личность или полномочия человека;
- принадлежность денег;
- завершение банковской операции;
- точный тип предмета при недостаточном разрешении;
- нарушение внутреннего правила без текста этого правила.

## Технический результат

Минимальный результат анализа:

```json
{
  "status": "done",
  "verdict": "violation",
  "violations": [
    {
      "type": "Название типа нарушения",
      "timecode_sec": 15.4,
      "description": "Что видно и почему это может быть нарушением",
      "evidence_frames": [
        {
          "timestamp_sec": 15.4,
          "image_base64": "<jpeg-base64>"
        }
      ]
    }
  ]
}
```
