# Локальные материалы анализа

Подробные metadata, labels, storyboards, clips и review исходного датасета хранятся в этой директории только локально и игнорируются Git.

Ожидаемые локальные файлы:

```text
analysis/
├── dataset_manifest.json
├── annotation_schema.json
├── preliminary_video_review.md
├── clips/
└── storyboards/
```

Эти материалы используются только в рамках Datathon26. Не добавляйте их в публичный репозиторий и не передавайте внешним AI-сервисам.

Общие безопасные требования находятся в `docs/requirements/DATATHON26_CASE_REQUIREMENTS.md`.
