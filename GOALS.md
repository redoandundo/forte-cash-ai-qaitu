# Цели проекта Qaitu

## Участие

Команда Qaitu участвует в Datathon26 и решает кейс ForteBank по локальному анализу видео кассовой зоны.

## Главная цель

Создать воспроизводимый локальный сервис, который принимает видеозапись, находит признаки возможного нарушения, возвращает временной интервал события, confidence и 1–3 JPEG-доказательства для ручной проверки.

## Ожидаемые результаты

- Обработка `.mov` без отправки содержимого во внешние сервисы.
- Публичный verdict строго `violation` или `no_violation`, с отдельным техническим статусом `failed`.
- Локализация одного или нескольких событий во времени.
- Объяснимые evidence-кадры.
- Воспроизводимая модель и inference pipeline.
- Пользовательский веб-интерфейс загрузки и просмотра результата.
- Публичный API с `X-API-Key` и асинхронным job lifecycle.
- Демонстрация на примерах Datathon26.

## Критерии успеха

- End-to-end путь от видео до результата работает на целевой машине.
- Полный анализ одного видео укладывается в лимит 300 секунд.
- API возвращает точную схему из ТЗ, включая 1–3 JPEG в base64.
- Split исключает утечку известных дубликатов.
- PyTorch и экспортированная модель проходят parity-check.
- Ошибки чтения, модели и evidence не превращаются в отрицательный verdict.
- Команда может воспроизвести demo по одной документированной инструкции.

## В scope

- Dataset audit и бинарная разметка.
- R3D-18 baseline и сравнение с X3D-XS при стабильном окружении.
- Локальный ONNX/TorchScript inference.
- Temporal aggregation и evidence.
- API, jobs, конфигурация и интеграция.
- Frontend для обязательного пользовательского сценария.
- Документация, tests, metrics и benchmark.

## Не входит в первый релиз

- Автоматическое юридическое решение.
- Идентификация личности или статуса человека по внешности.
- Облачное распознавание видео.
- Распознавание или идентификация лиц.
- Многоклассовая классификация неподтверждённых типов нарушений.
- RT-DETR/ByteTrack без подтверждённой необходимости и box-разметки.
- SmolVLM как обязательная production-зависимость.

## Ограничения

- Исходный набор мал: 42 видео.
- Тип нарушения не задан организаторами.
- В датасете есть дубликаты.
- Для некоторых сцен нужны внутренние правила ForteBank и экспертная проверка.
