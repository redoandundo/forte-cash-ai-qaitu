Дата замера: 17.10.2026.

## Вывод

На предоставленных видео модель уверенно укладывается в ограничение пять минут. Самый медленный результат — 5,71 секунды, что даёт запас примерно 52 раза.

## Выполненные ускорения

- API переведён со старого HOG baseline на `models/best_model.onnx`.
- Видео открывается и декодируется один раз.
- Кадры перекрывающихся окон переиспользуются.
- Окна обрабатываются пакетами по 32.
- ONNX-сессия кэшируется между запросами.
- ONNX Runtime включает полную оптимизацию графа и автоматически выбирает GPU при его наличии.
- Предобработка выполняется через NumPy и OpenCV без PyTorch в production path.

## Граница гарантии

Результат подтверждён для 40 роликов кейса, где максимальная длительность равна 142,53 секунды. Для произвольного видео длительностью в часы срок нельзя гарантировать только по ограничению размера файла; для production следует отдельно задать максимально допустимую длительность или очередь с SLA.
