# API contract для проверки жюри Datathon26

Источник: техническое задание ForteBank, раздел 10.

Статус: required external contract

## Аутентификация

Каждый запрос использует заголовок:

```http
X-API-Key: <team-api-key>
```

Запрос без корректного ключа отклоняется. Реальный ключ хранится только в secret/environment configuration и никогда не коммитится.

## Создание анализа

```http
POST /api/v1/analyze
Content-Type: multipart/form-data
X-API-Key: <team-api-key>
```

Обязательное поле:

- `file` — видео `.mov`.

Ответ содержит `job_id`:

```json
{
  "job_id": "3f2a9c1e"
}
```

## Получение статуса

```http
GET /api/v1/jobs/{job_id}
X-API-Key: <team-api-key>
```

Допустимые значения `status`:

- `processing`;
- `done`;
- `failed`.

## Завершённый анализ

Публичная схема должна сохранять точные имена полей:

```json
{
  "job_id": "3f2a9c1e",
  "status": "done",
  "verdict": "violation",
  "violations": [
    {
      "type": "Название типа нарушения",
      "timecode_sec": 44.2,
      "description": "Что видно на видео и почему это может быть нарушением",
      "evidence_frames": [
        {
          "timestamp_sec": 44.2,
          "image_base64": "/9j/4AAQ..."
        }
      ]
    }
  ]
}
```

## Поля результата

| Поле | Требование |
|---|---|
| `verdict` | строго `no_violation` или `violation` |
| `violations` | список; пустой при отсутствии нарушений |
| `type` | тип наблюдаемого события |
| `timecode_sec` | конкретный таймкод в секундах от начала |
| `description` | что видно и почему это может указывать на нарушение |
| `evidence_frames` | 1–3 JPEG в base64 |

В одном видео может быть несколько элементов `violations`.

## Техническая ошибка

При технической ошибке:

- `status` равен `failed`;
- ответ не подменяется `no_violation`;
- публичный ответ не содержит абсолютных путей и stack trace;
- дополнительное поле ошибки допускается, если оно не нарушает обязательные поля проверки.

## Временной лимит

Сервис обязан вернуть итог не позднее 5 минут после загрузки. Недоступность сервиса или отсутствие результата через 5 минут считается необработанным видео.

## Внутренние и внешние названия

Внутри pipeline разрешены `DetectedEvent`, `possible_violation` и дополнительные scores. API adapter обязан преобразовать их в точную внешнюю схему этого документа.

## Пример

```bash
curl -X POST https://team.example.kz/api/v1/analyze \
  -H "X-API-Key: <team-api-key>" \
  -F "file=@video_017.mov"
```

## Запреты

- Не использовать тестовые видео для обучения.
- Не публиковать и не передавать тестовые видео третьим лицам.
- Не передавать видео, кадры или их описания в облачные AI API.
- Не использовать распознавание или идентификацию лиц.
